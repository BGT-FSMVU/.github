# Bilişim Güvenliği Teknolojisi Programı

**Fatih Sultan Mehmet Vakıf Üniversitesi**

BGT-FSMVU, Fatih Sultan Mehmet Vakıf Üniversitesi  
Bilişim Güvenliği Teknolojisi Programının resmi GitHub organizasyonudur.

Bu organizasyon; öğrencilerimizin yazılım, siber güvenlik ve bilişim teknolojileri alanlarında geliştirdikleri projelerin paylaşılması, geliştirilmesi ve açık kaynak katkılarının desteklenmesi amacıyla oluşturulmuştur.

## 🎓 Öğrenci Projeleri

Öğrencilerimiz tarafından geliştirilen projeler bu organizasyon altında yayınlanmaktadır.

Projeler herkese açık olarak incelenebilir ve açık kaynak geliştirme süreçlerine uygun olarak katkıda bulunulabilir.

## 👥 Akademik Kadro

Program akademik personeli, öğrenci projelerinin geliştirilmesi ve akademik çalışmaların yürütülmesine katkı sağlamaktadır.

## 🤝 Projelere Katkı

Projelerimize katkıda bulunmak isteyenler:

- Issue açabilir,
- Projeleri fork edebilir,
- Pull Request gönderebilir,
- Geliştirme önerilerinde bulunabilir.
